# Specifications (Input)

This folder is the repository-level entry point for specification guidance.

## What to do

1. Open the placeholder project example under `[ProjectName]/spec/`.
2. Reuse the example template from `[ProjectName]/spec/specification_template.md`.
3. Create a real project folder at repository root and save your project-specific specification there:
   - `<RealProjectName>/spec/spec_<project_name>.md`
4. Invoke the agent using the real project spec file path.

## Notes

- Example specification materials are intentionally stored under `[ProjectName]/spec/` only.
- Do not use `[ProjectName]/` as the active project; it remains a placeholder example.
