# Specifications (Input)

This folder contains **specification documents** (functional requirements) used as the **main input** for the `@powerbi-AI-developer` agent.

## What to do

1. Start from the template: `spec/specification_template.md`
2. Create a project-specific copy in your project folder:
   - `<ProjectName>/spec/spec_<project_name>.md`
3. Invoke the agent using the project spec file path.

## Files

- `specification_template.md` — empty structured template
- `sample_spec.md` — complete example (Italian)
