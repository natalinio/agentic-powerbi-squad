# Code of Conduct

## Expected Behavior

Participants in this repository are expected to:

- communicate respectfully and stay focused on the technical problem
- provide constructive review feedback
- assume good intent while challenging ideas with evidence
- document concerns clearly, especially around safety, security, and compliance

## Unacceptable Behavior

The following is not acceptable in issues, pull requests, reviews, or discussions:

- harassment, personal attacks, or discriminatory language
- doxxing or sharing private information
- abusive, threatening, or intentionally disruptive behavior
- publishing secrets, credentials, or sensitive organizational data

## Enforcement

Maintainers may remove content, close discussions, or block participation when behavior conflicts with this code of conduct.
