# Project Specifications

Place your project functional specifications here.

## Expected usage

- Copy the global template from `spec/specification_template.md`
- Save your filled specification as:
  - `YourProjectName/spec/spec_<your_project_name>.md`
- Invoke the agent with the spec file path:
  - `@delivery-lead Build a Power BI project from YourProjectName/spec/spec_<your_project_name>.md`

## Notes

- This folder is intentionally separated from PBIP implementation artifacts.
- Keep specification files as Markdown (`.md`).
