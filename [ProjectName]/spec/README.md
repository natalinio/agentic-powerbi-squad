# Project Specifications

This folder contains the placeholder project's example specifications and templates.

## Contents

- `specification_template.md` — empty structured template example
- `sample_spec.md` — complete filled example
- project-specific specs copied into the placeholder only as repository examples

## Expected usage

- Review these files as examples only.
- For real work, create a new project folder at repository root.
- Copy the template into `<RealProjectName>/spec/spec_<your_project_name>.md`.
- Invoke the agent with the real project spec path.

## Notes

- This folder is intentionally separated from PBIP implementation artifacts.
- Keep specification files as Markdown (`.md`).
- `[ProjectName]/` remains a placeholder and must not become the active initialized project.
